A chess engine in under 4 KB of Python: alpha-beta search with iterative deepening, quiescence, transposition table and piece-square evaluation, playing the house gauntlet through the make.fun env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
